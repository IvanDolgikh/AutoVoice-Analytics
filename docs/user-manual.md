## 1. Назначение системы

AutoVoice Analytics — веб-приложение для автоматизированного контроля качества телефонных переговоров менеджеров дилерского центра. Система обеспечивает:

- автоматическую оценку звонков по заданным критериям скрипта продаж;
- визуализацию ключевых показателей эффективности (KPI) в режиме реального времени;
- формирование аналитических отчётов по сотрудникам, салонам и временным периодам;
- управление сценариями проверок, постановку целей и ведение журнала coaching-сессий;
- геймификацию рабочего процесса через систему рейтинга и достижений;
- взаимодействие с ИИ-ассистентом для оперативного получения аналитики.

Система предназначена для трёх категорий пользователей:
- **Директор** — полный доступ ко всем модулям, управление настройками;
- **Руководитель** — управление командой, coaching, постановка целей;
- **Сотрудник** — просмотр своих показателей и записей звонков.

## 3. Авторизация в системе

При открытии приложения отображается экран авторизации. Пользователю необходимо выбрать роль, под которой он входит в систему.

### 3.1 Порядок входа

1. Открыть приложение в браузере по адресу `http://localhost:5173`.
2. На экране приветствия нажать кнопку с нужной ролью:
   - **Директор** — доступ ко всем функциям, включая управление сотрудниками и настройку порогов;
   - **Руководитель** — доступ к аналитике команды, coaching и постановке целей;
   - **Сотрудник** — просмотр личных показателей и записей своих звонков.
3. После нажатия система автоматически переходит на главный экран — модуль «Статистика».

> **Рисунок 1.** Экран авторизации системы AutoVoice Analytics с выбором роли пользователя.

### 3.2 Выход из системы

Для выхода необходимо нажать кнопку с иконкой выхода (стрелка вправо) в правом верхнем углу шапки приложения. После подтверждения пользователь возвращается на экран авторизации.

## 5. Модуль «Статистика»

Модуль «Статистика» является главной аналитической страницей системы. Он открывается сразу после авторизации и предоставляет комплексный обзор показателей работы команды.

> **Рисунок 3.** Общий вид модуля «Статистика».

### 5.1 Строка периода и сравнение периодов

В верхней части страницы отображается текущий период анализа (например, «Февраль 2025») и кнопка **«Сравнить с прошлым периодом»**.

При нажатии кнопки под основными KPI-карточками появляется дополнительный ряд с данными предыдущего периода (январь 2025). Карточки предыдущего периода выделены пунктирной рамкой и содержат:
- значение показателя за прошлый месяц;
- пунктирный спарклайн динамики;
- дельту к текущему периоду со стрелкой и цветовым обозначением (зелёный — рост, красный — снижение).

Повторное нажатие скрывает ряд сравнения.

> **Рисунок 4.** Режим сравнения периодов: основные KPI текущего месяца (сверху) и данные предыдущего периода (снизу, пунктирная рамка).

### 5.2 KPI-карточки

Четыре карточки с ключевыми показателями отображаются в верхней части страницы:

| Карточка | Описание |
|---|---|
| **Всего звонков** | Общее количество звонков за период. Значение отображается крупным шрифтом цвета бренда. |
| **Входящих** | Количество входящих звонков. |
| **Исходящих** | Количество исходящих звонков. |
| **Средний балл / 13** | Средний балл оценки сотрудников по 13-балльной шкале. |

Каждая карточка содержит:
- **Иконку** — тематический символ в цветном круглом бейдже;
- **Тренд** — процент изменения относительно прошлого периода (зелёный — рост, красный — снижение);
- **Числовое значение** — крупно, в цвете индикатора;
- **Спарклайн** — мини-график динамики по дням за текущий период.

> **Рисунок 5.** KPI-карточки: четыре ключевых показателя с трендом и спарклайном динамики.

### 5.3 Топ-5 сотрудников и Зона внимания

Блок состоит из двух соседних карточек:

**Топ-5 сотрудников** — таблица лучших менеджеров по среднему баллу за период. Для каждого сотрудника отображаются:

- ФИО;

**Зона внимания** — список сотрудников с показателями ниже 70%. Для каждого отображаются балл, процент, динамика (тренд), количество звонков за период и цветной прогресс-бар. Внизу блока выводится рекомендация провести разбор звонков с данными менеджерами.

## 6. Модуль «Звонки»

Модуль «Звонки» предназначен для просмотра, фильтрации и детального анализа отдельных звонков.

> **Рисунок 13.** Общий вид модуля «Звонки» с фильтрами и таблицей звонков.

### 6.1 Панель фильтров

Над таблицей расположена панель фильтрации, позволяющая отобрать нужные записи:

- **Дата с / Дата по** — выбор периода через встроенный календарь (DatePicker). Поддерживается ввод вручную в формате ДД.ММ.ГГГГ.
- **Салон** — фильтрация по подразделению: «Автосалон Окружная», «Автосалон Федюнинского», «Автосалон Пермякова» или все салоны.
- **Тип** — фильтрация по типу вызова: «Входящий», «Исходящий» или все типы.

> **Рисунок 14.** Панель фильтрации звонков: выбор периода, салона и типа вызова.

### 6.2 Фильтрация по критериям (теги)

Под основными фильтрами расположен блок тегов — критериев оценки звонков. Каждый тег соответствует одному из 8 критериев скрипта:

- Приветствие
- Выявление потребности
- Обращение по имени
- Срок покупки
- Тест-драйв
- Срочность
- Сбор контакта
- Следующий контакт

Нажатие на тег активирует его (выделяется синим фоном). Таблица автоматически фильтруется и показывает только те звонки, в которых выбранный критерий **не был выполнен** — это позволяет быстро находить записи с конкретными нарушениями. Повторное нажатие снимает фильтр.

> **Рисунок 15.** Блок тегов-критериев: нажатие на тег фильтрует таблицу по звонкам с нарушением данного критерия.

### 6.3 Таблица звонков

Основной элемент модуля — таблица со списком звонков. Каждая строка содержит:

| Столбец | Описание |
|---|---|
| **Дата** | Дата звонка в формате ДД.ММ.ГГГГ |
| **Сотрудник** | ФИО менеджера, совершившего звонок |
| **Салон** | Подразделение, к которому относится менеджер |
| **Тип** | «Входящий» или «Исходящий» с иконкой стрелки |
| **Балл** | Числовой балл (из 13) с цветным прогресс-баром |
| **Критерии** | Цветные точки-индикаторы по каждому из 8 критериев (зелёная — выполнен, красная — нарушен) |
| **▼** | Кнопка раскрытия детальной панели |

Строки с одинаково низким баллом выделяются фоном. При нажатии на строку открывается детальная панель.

> **Рисунок 16.** Таблица звонков: список записей с баллами, прогресс-барами и индикаторами критериев.

При нажатии на строку таблицы под ней раскрывается детальная панель с двумя вкладками.

## 7. Модуль «Отчёты»

Модуль «Отчёты» обеспечивает формирование аналитических отчётов с возможностью экспорта данных.

> **Рисунок 20.** Общий вид модуля «Отчёты» с двумя типами отчётов.

### 7.1 Общие фильтры

В верхней части каждого отчёта расположены фильтры:
- **Период** — выбор даты «С» и «По» через DatePicker;
- **Салон** — фильтрация по подразделению.

### 7.2 Конверсионный отчёт

Конверсионный отчёт позволяет анализировать эффективность работы в иерархическом разрезе.

**Настройка уровней группировки** осуществляется методом перетаскивания (drag-and-drop): пользователь перетаскивает теги (Салон, Сотрудник, Тип звонка, Потребность) из блока доступных тегов в зону построения. Теги определяют иерархию строк отчёта. Добавленный тег можно удалить крестиком.

После настройки нажимается кнопка **«Сгенерировать отчёт»**. Система формирует таблицу конверсии с иерархической структурой:
- каждый уровень может быть раскрыт/свёрнут кликом;
- в столбцах отображаются этапы воронки: входящие → потребность → тест-драйв → договорённость;
- между столбцами показывается процент перехода на следующий этап.

Кнопки экспорта:
- **«Экспорт CSV»** — скачивание данных в формате CSV (открывается в Excel);
- **«Экспорт PDF»** — печать/сохранение текущего отчёта в формате PDF через диалог браузера.

> **Рисунок 21.** Конверсионный отчёт: зона drag-and-drop настройки уровней и сгенерированная таблица конверсии.

### 7.3 Балльный отчёт

Балльный отчёт формирует детальную таблицу оценок по каждому сотруднику и каждому критерию.

После нажатия **«Сгенерировать отчёт»** отображаются:

**Блок инсайтов** — три карточки:
- «Лучший сотрудник» — лидер по итоговому баллу с указанием показателя;
- «Слабый критерий» — критерий с наименьшим средним выполнением;
- «Тренд» — общая динамика показателей команды.

**Таблица оценок** — строки соответствуют сотрудникам, столбцы — критериям. Ячейки окрашены:
- зелёный — критерий выполнен полностью;
- оранжевый — частичное выполнение;
- красный — критерий не выполнен.

Последний столбец — итоговый балл. Заголовки столбцов кликабельны для сортировки (по возрастанию/убыванию).

### 8.2 Карточки сценариев

- **Отдел** — выпадающий список;
- **Описание** — текстовое описание;

## 9. Модуль «Групповые проверки»

Модуль «Групповые проверки» позволяет запускать массовую оценку нескольких сотрудников одновременно.

> **Рисунок 27.** Общий вид модуля «Групповые проверки».

### 9.1 Панель конфигурации проверки

Левая колонка содержит настройки проверки:
- **Выбор сценария** — выпадающий список доступных сценариев;
- **Период** — выбор дат «С» и «По»;
- **Минимальный порог** — ползунок (0–100%) для установки порогового значения балла;

Кнопка **«Запустить проверку»** инициирует процесс оценки с анимацией загрузки.

> **Рисунок 28.** Панель конфигурации групповой проверки.

### 9.2 Сводная статистика

После завершения проверки в правой части отображаются четыре карточки:
- **Проверено звонков** — общее количество;
- **Средний балл** — по всем проверенным звонкам;
- **Выполнение критериев** — средний процент;
- **Нарушений порога** — количество звонков ниже установленного порога.

> **Рисунок 29.** Сводная статистика групповой проверки: итоговые показатели после завершения.

### 9.3 Диаграмма результатов и тепловая карта

**Диаграмма** — горизонтальная столбчатая диаграмма (Chart.js) с результатами по каждому сотруднику. Цвет столбца зависит от значения (зелёный — выше порога, жёлтый — близко к порогу, красный — ниже). Пунктирная вертикальная линия обозначает установленный порог.

**Тепловая карта критериев** — матрица, где строки — сотрудники, столбцы — критерии. Интенсивность цвета ячейки отражает процент выполнения. Позволяет визуально определить системные проблемы команды.

> **Рисунок 30.** Диаграмма результатов проверки (вверху) и тепловая карта выполнения критериев (внизу).

### 9.4 Детальная таблица

Под диаграммами расположена таблица с детальными результатами по каждому сотруднику: ФИО, балл, процент, тренд относительно предыдущего периода и результат по каждому критерию.

## 13. Модуль «ИИ-ассистент»

Модуль «ИИ-ассистент» предоставляет интерфейс для диалога с искусственным интеллектом по вопросам аналитики, работы и обучения.

> **Рисунок 43.** Общий вид модуля «ИИ-ассистент».

### 13.1 Структура интерфейса

Страница разделена на две части:

**Левая панель (Sidebar):**
- Кнопка **«+ Новый чат»** — начало нового диалога;
- **История чатов** — список предыдущих диалогов с датой и первым сообщением;
- **Раздел «Быстрые запросы»** — 6 готовых запросов для часто задаваемых вопросов (статистика команды, слабые зоны, лучший сотрудник, анализ звонков, тренды, рекомендации).

> **Рисунок 44.** Левая панель ИИ-ассистента: история чатов и быстрые запросы.

**Правая область (Чат):**
- **Приветственное сообщение** с описанием возможностей ассистента;
- **Область сообщений** — чередование реплик пользователя (справа, синий фон) и ответов ИИ (слева, белый фон);

**Быстрые запросы:**
Нажатие на кнопку быстрого запроса автоматически отправляет предустановленное сообщение и получает структурированный ответ.

**Форматирование ответов ИИ:**
Ответы могут содержать:
- блоки кода с синтаксической подсветкой;
- маркированные и нумерованные списки;
- выделение важных данных жирным шрифтом;
- таблицы с аналитическими данными.

## 14. Центр уведомлений

Центр уведомлений доступен через иконку колокольчика в шапке приложения.

### 14.1 Индикатор уведомлений

На иконке колокольчика отображается красный бейдж с количеством непрочитанных уведомлений. Если все уведомления прочитаны — бейдж скрывается.

### 14.2 Панель уведомлений

При нажатии на колокольчик открывается выпадающая панель (340 пикселей шириной) с:

**Заголовком** и кнопкой **«Прочитать все»** (если есть непрочитанные).

**Фильтром по категориям:**
- «Все» — все уведомления с общим счётчиком;
- «Нарушения» — предупреждения о нарушениях порогов;
- «Система» — системные события (завершённые проверки, достижения целей);
- «Информация» — информационные сообщения.

**Списком уведомлений.** Каждое уведомление содержит:
- цветной значок типа (красный — нарушение, зелёный — успех, жёлтый — предупреждение, синий — информация);
- заголовок, описание и время («5 мин назад»);
- **синюю полоску** слева для непрочитанных;
- кнопку удаления (крестик), появляющуюся при наведении.

Нажатие на уведомление помечает его как прочитанное (синий фон исчезает). Панель закрывается кликом вне её области.

> **Рисунок 46.** Центр уведомлений: выпадающая панель с фильтрами по категориям и списком уведомлений.
