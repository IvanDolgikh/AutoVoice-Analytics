## 1. Назначение и роли

AutoVoice Analytics — веб-приложение для автоматизированного контроля качества телефонных переговоров менеджеров дилерского центра. Система оценивает звонки по критериям скрипта продаж, визуализирует KPI, формирует отчёты и ведёт журнал coaching-сессий.

Система поддерживает три роли пользователей с разграниченным доступом:

| Роль | Доступные модули |
|---|---|
| **Директор** | Все модули: статистика, звонки, отчёты, сценарии, групповые проверки, цели, coaching, ИИ-ассистент |
| **Руководитель** | Статистика команды, звонки команды, отчёты, групповые проверки, цели, coaching, ИИ-ассистент |
| **Сотрудник** | Мой дашборд, мои звонки, рейтинг команды, coaching, ИИ-ассистент |

**Системные требования:** браузер Google Chrome / Firefox / Edge версии 110+, разрешение экрана не менее 1280 × 720 пикселей.

## 2. Авторизация

При открытии приложения по адресу `http://localhost:5173` отображается экран авторизации.

**Порядок входа:**
1. Ввести логин и пароль (в демо-режиме: `admin` / `123`).
2. Выбрать роль из выпадающего списка: Директор, Руководитель отдела или Сотрудник.
3. Нажать кнопку **«Войти»**.

После успешного входа система автоматически переходит на главный экран — модуль «Статистика». Для выхода из системы необходимо нажать кнопку с иконкой выхода (стрелка вправо) в правом верхнем углу.

## 3. Главный интерфейс

После авторизации отображается главное окно, состоящее из трёх зон:

- **Шапка (Header)** — логотип системы, панель навигации с вкладками модулей, кнопка смены темы, центр уведомлений, информация о пользователе с кнопкой выхода.
- **Рабочая область** — содержимое активного модуля, занимает основную часть экрана.
- **Виджет поддержки** — кнопка вызова службы технической поддержки в правом нижнем углу.

Набор вкладок навигации меняется в зависимости от роли пользователя: директор видит все восемь разделов, сотрудник — только пять.

## 4. Модуль «Статистика» — директор

Модуль открывается по вкладке **«Статистика»** и является главной аналитической панелью системы для роли директора. Страница организована в несколько блоков.

### 4.1 KPI-карточки и сравнение периодов

В верхней части расположены четыре карточки ключевых показателей: **Всего звонков**, **Входящих**, **Исходящих**, **Средний балл / 13**. Каждая карточка содержит текущее значение, процентное изменение относительно прошлого периода и мини-график (спарклайн).

Кнопка **«Сравнить с прошлым периодом»** разворачивает дополнительный ряд карточек с показателями предыдущего месяца и абсолютным отклонением.

> **Рисунок 3.** KPI-карточки модуля «Статистика» с показателями текущего и прошлого периода.

### 4.2 Топ-5 сотрудников и зона внимания

Левый блок отображает пятёрку лучших сотрудников с баллами и прогресс-барами. Правый блок «Зона внимания» выводит сотрудников с показателем ниже 70%, их тренд и количество звонков за период.

### 4.3 Аналитические диаграммы

- **Распределение баллов** — горизонтальная гистограмма по диапазонам (0–4, 5–8, 9–11, 12–13).
- **Воронка конверсии** — количество звонков по этапам (входящие → выявление потребности → тест-драйв → договорённость о визите).
- **Типы звонков** — кольцевая диаграмма с разбивкой входящих и исходящих.
- **Динамика качества** — линейный график среднего балла по месяцам с линией цели.
- **Выполнение критериев** — радарная диаграмма с восемью критериями скрипта.
- **Тепловая карта активности** — матрица звонков по дням недели и часам суток.

> **Рисунок 4.** Аналитические диаграммы модуля «Статистика»: воронка конверсии, распределение баллов, радарная диаграмма критериев и тепловая карта активности.

## 5. Модуль «Статистика» — руководитель и сотрудник

Содержимое модуля адаптируется под роль пользователя.

### 5.1 Дашборд руководителя

Руководитель видит агрегированные показатели своей команды (6 сотрудников): средний балл, количество звонков, лучший результат и число сотрудников, требующих внимания. Доступны горизонтальная гистограмма баллов по каждому сотруднику с цветовым кодированием (зелёный ≥ 70%, жёлтый 55–69%, красный < 55%), радарная диаграмма команды, список отстающих и таблица «Приоритеты обучения» с тремя слабейшими критериями.

### 5.2 Личный дашборд сотрудника

Сотрудник видит только свои показатели: балл, количество звонков, место в рейтинге и процент выполнения. Радарная диаграмма сравнивает его критерии со средним по команде. Ниже — полный рейтинг всей команды с выделением собственной позиции («Я»-метка). Блок «Зоны роста» указывает критерии, требующие улучшения.

## 6. Модуль «Звонки»

Модуль **«Звонки»** / **«Мои звонки»** предоставляет доступ к списку звонков с возможностью фильтрации и детального анализа каждого.

### 6.1 Фильтрация

Панель фильтров в верхней части позволяет отбирать звонки по: дате (диапазон), салону, типу (входящий/исходящий), тегам качества (8 критериев скрипта). Результаты фильтрации отображаются в таблице немедленно.

### 6.2 Таблица звонков

Таблица содержит колонки: дата, сотрудник (только для директора и руководителя), салон, тип, балл с прогресс-баром и кнопку «Детали». Строки с низким баллом (< 60%) выделяются красным фоном.

### 6.3 Детальная карточка звонка

По нажатию кнопки **«Детали»** открывается панель с:
- **Кастомным аудиоплеером**: визуализация звуковой волны с маркерами нарушений скрипта (красные области), кнопками воспроизведения/паузы, временной шкалой и выбором скорости (0.75×, 1×, 1.5×, 2×).
- **Вкладкой «Транскрипт»**: диалог с разметкой реплик менеджера и клиента.
- **Вкладкой «Оценка»**: результаты по восьми критериям скрипта с пояснениями.
- **Вкладкой «Метаданные»**: техническая информация о записи.
- **Тегами**: ярлыки нарушений с возможностью добавления и удаления.

> **Рисунок 6.** Модуль «Звонки»: таблица с фильтрами и детальная карточка звонка с кастомным аудиоплеером и оценкой по критериям.

## 7. Модуль «Отчёты»

Модуль **«Отчёты»** позволяет формировать два типа аналитических отчётов.

**Отчёт по критериям** — матрица выполнения восьми критериев скрипта каждым сотрудником. После нажатия кнопки **«Сформировать»** появляется таблица с цветовым кодированием ячеек: зелёный — критерий выполнен, красный — не выполнен.

**Отчёт по конверсии** — воронка продаж с количеством и долей звонков на каждом этапе работы с клиентом.

Для каждого отчёта доступен экспорт в двух форматах:
- **CSV** — нажать кнопку «Экспорт CSV» для загрузки файла таблицы.
- **PDF** — нажать кнопку «Экспорт PDF» для открытия диалога печати браузера с готовым документом.

> **Рисунок 7.** Модуль «Отчёты»: матрица критериев с цветовым кодированием и кнопки экспорта в CSV и PDF.

## 8. Модуль «Сценарии» и «Групповые проверки»

### Сценарии (доступно директору)

Модуль управляет шаблонами скриптов звонков. Каждый сценарий содержит название, статус (активный/черновик), количество критериев и дату последнего изменения. Поддерживается создание нового сценария и редактирование существующего.

### Групповые проверки (директор и руководитель)

Модуль позволяет запускать пакетную оценку звонков по выбранному сценарию. Пользователь настраивает параметры проверки (период, сотрудники, сценарий), запускает проверку и просматривает результаты в сводной таблице.

> **Рисунок 8.** Модуль «Групповые проверки»: настройка параметров пакетной оценки и сводная таблица результатов.

## 9. Модуль «Цели и KPI»

Модуль **«Цели»** позволяет ставить и отслеживать цели по подразделениям.

**Сводные карточки** в верхней части показывают общее количество целей, число целей «по плану», «под угрозой» и «достигнутых».

**Фильтр по отделу** — кнопки переключения позволяют отобразить цели конкретного подразделения или все сразу.

**Карточки целей** содержат: название, прогресс-бар с цветовым статусом (зелёный — по плану, жёлтый — под угрозой, красный — просрочена), текущее и целевое значение, дату дедлайна и обратный отсчёт оставшихся дней.

**Форма добавления цели** позволяет создавать новые цели с указанием названия, целевого процента, текущего значения, дедлайна и отдела.

> **Рисунок 9.** Модуль «Цели и KPI»: сводные карточки, фильтр по отделам и карточки целей с прогресс-барами.

## 10. Модуль «Coaching-журнал»

Модуль **«Coaching»** фиксирует сессии индивидуальной работы с сотрудниками.

**Блок статистики** содержит четыре показателя: всего сессий, проведено, запланировано, средний прирост балла после сессии.

**Фильтр по статусу** — кнопки «Все», «Запланированы», «Проведены» позволяют отфильтровать карточки.

**Карточки сессий** отображают: имя сотрудника, дату, статус, балл до и после сессии со стрелкой изменения, фокусные области (теги критериев) и заметки тренера. Для запланированных сессий доступна кнопка **«Провести»**, которая переводит сессию в статус «Проведена» и фиксирует прирост балла.

> **Рисунок 10.** Модуль «Coaching-журнал»: статистика сессий, фильтр и карточки с результатами проведённых и запланированных встреч.

### Вкладка «Рейтинг»

## 12. ИИ-ассистент

Модуль **«ИИ-ассистент»** предоставляет интерфейс чата с системой на основе искусственного интеллекта.

Пользователь вводит вопрос в поле сообщения и нажимает кнопку отправки или клавишу Enter. Ассистент анализирует запрос и возвращает ответ в формате диалога. Поддерживаются вопросы об аналитике звонков, рекомендациях по сотрудникам и интерпретации показателей.

В верхней части доступны кнопки быстрых запросов для частых сценариев использования.

> **Рисунок 12.** Модуль «ИИ-ассистент»: интерфейс чата с историей диалога и полем ввода запроса.

## 13. Уведомления и личный кабинет

### Центр уведомлений

Кнопка с иконкой колокольчика в шапке приложения открывает панель уведомлений. На иконке отображается красный счётчик непрочитанных сообщений.

**Панель уведомлений** содержит:
- Заголовок с кнопкой «Прочитать все».
- Фильтры по категориям: Все, Нарушения, Система, Информация.
- Список уведомлений: иконка типа, заголовок, текст, время. Непрочитанные выделены синей левой полосой и голубым фоном.

Щелчок по уведомлению отмечает его прочитанным. Кнопка «×» удаляет уведомление. Панель закрывается нажатием за её пределами.

> **Рисунок 13.** Центр уведомлений: выпадающая панель с фильтрами, списком непрочитанных уведомлений и кнопкой «Прочитать все».

## 14. Личный кабинет

Щелчок по блоку пользователя в правом верхнем углу (имя и роль) открывает личный кабинет.

**Шапка профиля** содержит синий баннер с аватаром, именем пользователя, ролью, датой регистрации и опытом работы в системе.

Профиль организован в четыре вкладки:

- **«Личные данные»** — редактируемые поля: ФИО, email, телефон, должность, салон. Кнопка «Сохранить» фиксирует изменения.
- **«Моя статистика»** — сводные карточки личных KPI и временная шкала последних действий в системе.
- **«Настройки»** — переключатели уведомлений (email, push, SMS) и параметры интерфейса.
- **«Безопасность»** — смена пароля с индикатором надёжности и список активных сессий с возможностью их завершения.

> **Рисунок 14.** Личный кабинет пользователя: шапка профиля с аватаром и вкладка «Личные данные» с формой редактирования.

## 15. Тёмная тема

Система поддерживает тёмный режим отображения. Для переключения необходимо нажать кнопку с иконкой луны / солнца в правом верхнем углу шапки приложения.

В тёмном режиме все элементы интерфейса — фон, карточки, таблицы, диаграммы, тексты и панели — переключаются на тёмную цветовую схему. Выбранная тема применяется ко всем модулям системы немедленно без перезагрузки страницы.
